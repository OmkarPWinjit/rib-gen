## Installation
### Install via VS Code Marketplace
1. Open VS Code
2. Go to Extensions view (`Ctrl+Shift+X`)
3. Search for "containercodegen"
4. Click Install

### Install from VSIX
1. Download the `.vsix` file
2. Open VS Code
3. Go to Extensions view
4. Click the ellipsis (`...`) and choose "Install from VSIX..."
5. Select the downloaded `.vsix` file

## Usage
- To activate the extension, press `Ctrl+Shift+P` and search for `rib.gen.container`.
- Use the following keyboard shortcut: `Ctrl+Alt+X` (Windows/Linux), `Cmd+Alt+X` (Mac).
